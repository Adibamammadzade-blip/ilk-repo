# Wikilinks

**Wikilinks** (`[[Page Name]]`) are the standard internal cross-referencing syntax used across Obsidian, Roam Research, and the [[LLM Wiki Pattern]].

## Syntax & Features
- **Direct Link**: `[[Target Page]]` links to `Target Page.md`.
- **Aliased Link**: `[[Target Page|Custom Display Text]]` changes the rendered anchor text without changing the target destination.
- **Header Link**: `[[Target Page#Section Header]]` jumps directly to an internal heading.

## Role in LLM Wiki
Wikilinks enable bidirectional graph navigation, automatic graph view clustering in Obsidian, and machine-readable reference tracking for tools like [[wiki_tools]].

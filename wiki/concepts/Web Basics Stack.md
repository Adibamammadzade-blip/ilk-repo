# Web Basics Stack

The **Web Basics Stack** represents a minimalist client-side trio consisting of HTML5, CSS3, and JavaScript without external runtime frameworks.

## Implementation in [[ilk-repo]]
1. **Markup** (`html/index.html`): Semantic HTML document structure with UTF-8 encoding and responsive viewport configuration.
2. **Styling** (`css/index.css`): Box-model resets (`box-sizing: border-box`), full viewport height sizing (`100vh`), and dark mode aesthetics.
3. **Behavior** (`js/index.js`): Dynamic DOM query selector (`document.querySelector("h1")`) and inline style modifications.

# ilk-repo

## Overview
**ilk-repo** is a multi-language repository designed as a personal sandbox and foundational learning project, incorporating web technologies (HTML, CSS, JavaScript) and Python programming. It now also hosts an [[persistent-knowledge-bases|LLM-maintained Wiki]] knowledge system.

## Project Structure & Stack
- **Frontend:**
  - HTML5 (`html/index.html`)
  - CSS3 (`css/index.css`)
  - Vanilla JavaScript (`js/index.js`)
- **Backend / Scripting:**
  - Python 3.x (`python/main.py`)
- **Knowledge Engine:**
  - LLM Wiki Layer (`wiki/`, `raw/`, `AGENTS.md`, `GEMINI.md`)

## Key Modules & Roles
- **Python Demonstration:** Contains an OOP `Repository` model and foundational data structure examples.
- **Local Search Engine (`python/wiki_search.py`):** Standalone zero-dependency search tool for ranking and querying wiki notes.
- **Web UI:** Minimal dark-themed starting page.

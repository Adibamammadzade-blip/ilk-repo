# Source: ilk-repo Codebase

- **Source Path**: `html/`, `css/`, `js/`, `python/`
- **Primary Languages**: Python, JavaScript, CSS, HTML
- **Author**: [[Suleiman]]

## Structure Overview
- **`html/index.html`**: Web entry point containing the main heading `<h1>My first repository</h1>` linking to external CSS.
- **`css/index.css`**: Dark theme stylesheet (black background, white text, centered header).
- **`js/index.js`**: DOM manipulation script targeting the `<h1>` element and applying accent styling (`red`).
- **`python/main.py`**: Educational starter script covering Python fundamentals (functions, lists, dictionaries, list comprehensions, and a `Repository` OOP class).

## Key Code Elements
- **Repository Class** (`python/main.py`): Models a Git repository instance with `name`, `branch`, and status reporting.
- **Languages Listed in Project**: HTML, CSS, JavaScript, Python.
